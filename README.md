- Batch convert full playlists
- No file size limit
- Offline conversion — no upload needed

## FAQ

**What's the max audio quality?**  
320 kbps MP3 or lossless FLAC — depends on the original YouTube audio stream.

**Are ID3 tags filled automatically?**  
Yes. The tool pulls title, channel name and thumbnail from YouTube and writes them into the file.
